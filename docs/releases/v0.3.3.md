## What is new in 0.3.3

A safety and cleanliness release: no new features, a lot fewer ways for things to go wrong.

**Privacy**
- **Jaffer no longer keeps what you wrote or Claude answered.** The live state of Claude Code (what drives the mole and the cost figure) used to hold a redacted copy of your last prompts, commands, file names and replies, and sent it to every window. Nothing showed it, so nothing holds it now: only whether Claude works, waits or is done, its background agents and what its answers cost. The path of the transcript never leaves the daemon.
- **A program in the terminal can no longer read your clipboard.** Writing to it (`ssh`, scripts, OSC 52) still works; asking for what you copied now gets nothing.
- **Notification Center no longer gets raw commands.** The "long command finished" notification redacts secrets and does not name a sensitive command at all.
- **Redaction learned more:** passwords glued to `-p` (`mysql -pSecret`, `7z -pSecret`), `sshpass -p`, `docker login -p`, `curl -u user:password`, `openssl -passin pass:…`, quoted values with spaces (`--password "two words"`, `"password": "two words"` in JSON), and `cat .env` / `printenv NAME` are never recorded.
- Memory curation can never be billed to an API key in your environment: it runs on your Claude login only.

**Safety**
- A file dropped on the window can no longer navigate it to another page that would get the daemon bridge.
- **Redaction could freeze the terminal**: one rule took 10 seconds on 9 KB of text with repeated dots. Fixed (6 ms) and covered by timing tests.
- Jaffer no longer deletes a skill of your own named `jaffer-…` in `~/.claude/skills`, no longer garbles your `CLAUDE.md` when a memory contains `$&`, writes through a symlinked `CLAUDE.md` or `settings.json` and keeps its permissions, and `jaffer reset` refuses a folder that is a code checkout.
- An agent can no longer forget a pinned memory, and a description only forgets a memory that really looks like it. Undoing an old run no longer undoes what you did to its memories since. Rules no longer rewrite a memory you pinned or edited, or fill the undo log with "seen again" lines.
- A second daemon starting at the same moment no longer takes the first one's socket; a shell that dies at once is no longer respawned in a loop, and a failed respawn is retried; the terminal's own focus and mouse reports are no longer taken for you answering Claude (the notification and the mole stayed right).

**Fixes**
- The Notes tab no longer rewrites (or cuts) `NOTES.md` when merely opened, and no longer loses what you typed if you leave it within half a second.
- Clicking the words next to "Add memory tools" or "Reset…" no longer presses the button. The Open at login switch shows its real state. Dialogs take the keyboard and give it back. First run can no longer be skipped past by a shortcut.
- `jaffer remember --pin Always use pnpm` now remembers the whole sentence. A bracketed phrase before a model's JSON no longer makes a reflection come back empty. Reflections after the episode log was pruned are no longer missed.
- The spinner no longer mistakes `git log --grep claude` for Claude Code.

**Under the hood:** about 170 new tests (437 unit and 23 UI in all), the unused code behind all of this removed, and the dead fields of the live state, the screen snapshot and the RPC layer gone.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
