## What is new in 1.1.0

**A side panel with what Claude Code is doing right now and your past conversations.** Jaffer is still one window, one shell and a companion: no tabs, no splits, no second window, no chat box, and nothing is ever typed into your shell except `claude`. The panel only shows what the window and the menu bar already had.

### The side panel
- **It sits at the right of the terminal and is open by default.** `⌘B` (or the button at the far right of the title bar, *Toggle side panel* in the palette, *View → Toggle Side Panel*, or *Settings → Appearance → Show the side panel*) opens and closes it. Drag its left edge to change its width (220 to 480 px; the arrow keys work on the edge too). Open or closed, and the width, are remembered.
- **The terminal fits once.** Opening, closing or finishing a drag resizes the terminal one time, not on every pixel, so Claude Code does not redraw over and over while you move the edge.
- **Now.** A card at the top: whether Claude is not running, idle, working or needs you, the tool it uses and how long the turn has taken, a bar against how long a turn usually takes, the cost so far (an estimate, as everywhere, and only with *Show what each answer cost*), today's total against your daily budget, one line for each running background agent, what this turn did (`3 reads · 2 edits · 1 shell`) and up to eight files Claude edited (click one to show it in Finder). When a turn ends it shows the summary instead (`Claude finished in 1m 12s · 1 read · ≈ $0.04`). When Claude needs you it names the tool and says to answer in the terminal: Jaffer still answers nothing.
- **Past conversations.** Below it: the 50 newest conversations Claude Code kept, grouped under *Today*, *Yesterday* and the date, each with its folder, the time, how long it lasted and an estimated cost. Type to filter by folder. **A click or Enter copies `claude --resume <id>`** and says so; pasting it in the terminal and pressing Return is yours. The list is read when the panel opens, after a finished turn and with its refresh button, never while the panel is closed, and it is only kept in memory.
- **`⇧⌘O` now opens the panel** (if it was closed) and puts the cursor in the search. It used to open a list over the terminal; that list is gone. *All Past Conversations…* in the menu bar icon's menu does the same.
- **What is read has not changed.** From Claude Code's transcripts Jaffer still takes only each conversation's id, folder, first and last time and token counts: never a prompt, a reply or a tool's input. Nothing is written to disk except two settings in `config.json` (`panel.open` and `panel.width`).

### Two fixes
- **No bright line down the right edge.** The terminal's search ruler drew its border as a pale line along the whole right edge; it is transparent now.
- **The five newest past conversations are right in the menu bar icon's menu**, and they are loaded as soon as the icon exists, so the first right-click already has them.

**What happens when you update**
- Nothing is moved or deleted. The panel is open the first time you start 1.1.0, and `panel` appears in `~/.jaffer/config.json` once you change it. Jaffer's hooks in `~/.claude/settings.json` are unchanged (the same eleven events). Updating from 0.5.x or earlier still runs the one-time clean-up of 0.6.0 (see below).

**By hand**
- Not yet checked on a real Mac, and not verified until the owner has checked it there: how the panel looks with blur and vibrancy (and with blur off), how its resize feels at the edge, `⌘B` through the real menu (the menu's accelerator and the page's own key both arrive; one press should be one toggle), the title-bar button, and the menu bar menu's first right-click with the five conversations. The README's "Not verified here" lists these with the older checks, which are still open.
- `claude --resume` and `claude -c` are yours to type or paste, as before.

**Coming from 0.5 or earlier?** Jaffer has been a plain terminal since 0.6.0: the memory, the saved screen, *Resume Claude* and *Restart Claude Code*, the login agent and the Safety edges are gone, and quitting ends the shell and anything running in it (`⌘Q` asks first when Claude Code is working or a command runs; a logout, restart or shutdown and the Dock's *Quit* do not ask). On the first start Jaffer cleans up what they left, once (up to 30 seconds): it removes the login agent, **copies `~/.jaffer/memory/NOTES.md` and `POLICY.md` to `~/.jaffer-memory-backup/`** if you wrote something in them, **deletes `~/.jaffer/memory` and `~/.jaffer/session`**, removes only Jaffer's own entries from Claude Code's files (the marked block in `~/.claude/CLAUDE.md`, the `jaffer-*` skills, the `jaffer` MCP server) and drops the settings that no longer exist. **To keep anything from the memory, copy `~/.jaffer/memory` before you open this version for the first time** (if you update from inside the app, copy it before you click *Update and restart*). `jaffer config set migrated 0` runs the clean-up again; *Settings → Reset* does the same and more. If an older Jaffer's session is still running in the background, one dialog asks to end it (the default button is Quit).

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
