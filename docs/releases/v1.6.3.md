## What is new in 1.6.3

**Cleans up after voice mode.** The first start deletes the voice model files and the leftover voice settings.
- `~/.jaffer/voice` (about 175 MB if you downloaded the models) is removed.
- The unused `voice` and `permissions.voice` entries leave `config.json`.

<!-- card-end -->

**Jaffer 1.6.3 finishes taking voice out.** Voice mode was removed in 1.6.2; this update frees the disk space it left behind. It deletes only files inside Jaffer's own folder, adds no setting, writes nothing new, types nothing and changes no signing, entitlement or update setting. The notes of 1.6.2 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
