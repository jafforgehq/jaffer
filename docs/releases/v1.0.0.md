## What is new in 1.0.0

**Forty additions to a terminal that is still calm.** Jaffer is still one window, one shell and a companion: no tabs, no splits, no second window, no chat box, and nothing is ever typed into your shell except `claude`. What changed is how much the window tells you about what you and Claude Code just did.

### The companion and the title bar
- **The companion notices the tool.** The mole shows a book while Claude reads, a hammer while it writes, an antenna for the web and a hard hat for an agent; helper moles show their own agent's tool; the five scenes change colour or rhythm.
- **It dozes** after ten quiet minutes and wakes at any activity. **It celebrates a fix:** a command that failed three or more times in a row (same text) and then works plays a short burst of sparks. **A bell makes it flinch**, and bounces the Dock icon once if the window is behind.
- **The ring shows progress.** It fills against how long a turn usually takes (the median of your last ones; it just spins until there is one), stays full and pulses when a turn runs long, and turns dotted while Claude compacts its context (a toast says so). Hover it for the session clock (`Claude · 42 min · 9 turns · ≈ $1.20`) and each running agent's time.
- **A tool strip**, 2 pixels under the title bar: this turn's tool calls as segments coloured by kind, red when one failed, as wide as they took; hover for the name and time.
- **Chips:** *needs you* (the tool and what it asks, with "2nd time" when you already answered a prompt for that tool this session), *editing* (the file Claude is writing; click to show it in Finder), git counts after the branch (`+2 ~3 ?1 ↑1 ↓0`).

### Terminal
- **Command blocks.** A mark beside every command: green, red or still running. Hover for when it started and how long it took, and the output lights up; click to select it; ⌘↑ / ⌘↓ jump between prompts. Right-click: copy the command, copy the output, save the output to a file, copy as Markdown (`⌥⌘C` does that for the selection). Scrolled up into long output, the command and its mark stay pinned at the top.
- **When you come back**, a command that took 30 seconds or more while the window was behind gets a toast (`make finished in 4m 12s (exit 0)`).
- **Pasting several lines asks first** (*Paste* or *Cancel*). **File paths are links:** ⌘-click `src/app.ts:12` to show it in Finder, or open it in your editor (set a link such as `vscode://file/{path}:{line}:{col}` in *Settings → Terminal*; only editor links are allowed). A running dev server gets a `:5173 ↗` chip.
- **Find** says `3 of 41`, `⌘G` / `⇧⌘G` go to the next and previous match, and the matches are marked on the scroll bar. **Recent commands** (`⌘R`) lists this session's commands and copies the one you pick (nothing is typed). **Pin a line** (`⇧⌘L`; up to three). A column ruler at 80, 100 or 120. A switch for inline images.

### Claude Code
- **A cost that grows while Claude works** (greyed, `≈ $0.03 so far`), **today's total**, an optional **daily budget** (the figure turns yellow at 80 % and red past it; nothing is stopped) and, on hover, two small lines for the last 20 turns' length and cost. Still an estimate at API list prices, and it says so.
- **A summary when a turn ends** (10 seconds or more): how long, what it did (`3 reads, 2 edits, 1 shell`), the cost, and the files it edited, each a button that shows it in Finder.
- **Hook health** in *Settings → Claude Code*: the eleven hook events and when each was last seen, with a warning when `Stop` has not arrived for over an hour.

### Visual
- **The theme can follow macOS or the time of day** (light from 07:00 to 19:00), with a 1 second crossfade. **A glow** on the window's edge (a pulse when Claude needs you, steady while it works, a flash when a turn ends). **The folder name slides** when it changes. **Blur behind the window** can be switched off (the window is then solid).

### System
- **Focus mode** (`⌥⌘F`): the title bar, strip and companion fade, notifications are held, and leaving it shows one summary (`While you were focused: Claude finished twice, 1 command failed`). It is `⌥⌘F` and not `⌃⌘F` because macOS keeps `⌃⌘F` for full screen.
- **An optional strip of CPU, memory and battery** in the title bar (off by default; sampled every 5 seconds only while it is on).

**What the rules say now.** Jaffer still writes no screen, scrollback, command history, command output or transcript text to disk, and everything it shows is redacted. Two rules were narrowed on purpose, and both only for memory: Jaffer's watcher now remembers, while it runs, which tools Claude used, how many calls and how long they took, whether one failed, and the names of the files Claude edits (never a key, a credential, an `.env` file or anything else that looks sensitive); and the window remembers this session's commands (for the marks and for `⌘R`), your pinned lines, the last 20 turns, how often you answered each tool and today's estimated cost. None of it is written anywhere, and all of it is gone when you quit. The only things added to your settings file are the new settings, and one number Jaffer keeps for the ring (`claude.typicalTurnMs`, the typical turn length).

**What happens when you update**
- Nothing is moved or deleted. The new settings appear in `~/.jaffer/config.json` with their defaults the first time they are saved.
- Jaffer's own hooks in `~/.claude/settings.json` get an **eleventh event, `PreCompact`**, when the new app's terminal starts (the same rewrite of its own `# jaffer-managed` entries that it always does; your own hooks and settings are untouched).
- After each prompt Jaffer now runs `git status` in your project (one second at most, no lock taken). It skips a repository whose own config names a filter program, and a Mac without the developer tools.
- Blocks, pins and recent commands start empty: they are about what you do from now on.

**Changed or left out**
- Output is not folded (the terminal has no folding) and there is no soft-wrap toggle (long lines always wrap). Kitty graphics are not supported (sixel and iTerm2 images are, and have a switch).
- *Needs you* in the title bar names the tool and Claude's own wording, not the command.
- Focus mode is `⌥⌘F`.

**By hand**
- Not yet checked on a real Mac, and not verified until the owner has checked it there: the tooltips and clicks in the title bar under macOS's drag regions; *Blur* off; `⌘↑`, `⌘↓`, `⌘G`, `⌘R`, `⇧⌘L`, `⌥⌘C` and `⌥⌘F` through the real menu; the resource strip and the battery on real hardware; *Follow macOS / time of day* on a real Mac; the scroll bar's match marks; opening a path in a real editor; focus mode's held notifications and its summary in the packaged app; the Dock bounce for the bell; the git guard on a Mac without the developer tools; and the first start after the update adding `PreCompact` to your real hooks. The older checks of the 0.6 line (the quit question, Reset in the packaged app, staying awake with a closed lid and a notification you can see) are still open too; the README's "Not verified here" lists them all.
- `claude --resume` and `claude -c` are yours to type, as before.

**Coming from 0.5 or earlier?** Jaffer has been a plain terminal since 0.6.0: the memory, the saved screen, *Resume Claude* and *Restart Claude Code*, the login agent and the Safety edges are gone, and quitting ends the shell and anything running in it (`⌘Q` asks first when Claude Code is working or a command runs; a logout, restart or shutdown and the Dock's *Quit* do not ask). On the first start Jaffer cleans up what they left, once (up to 30 seconds): it removes the login agent, **copies `~/.jaffer/memory/NOTES.md` and `POLICY.md` to `~/.jaffer-memory-backup/`** if you wrote something in them, **deletes `~/.jaffer/memory` and `~/.jaffer/session`**, removes only Jaffer's own entries from Claude Code's files (the marked block in `~/.claude/CLAUDE.md`, the `jaffer-*` skills, the `jaffer` MCP server) and drops the settings that no longer exist. **To keep anything from the memory, copy `~/.jaffer/memory` before you open this version for the first time** (if you update from inside the app, copy it before you click *Update and restart*). `jaffer config set migrated 0` runs the clean-up again; *Settings → Reset* does the same and more. If an older Jaffer's session is still running in the background, one dialog asks to end it (the default button is Quit).

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
