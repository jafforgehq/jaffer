## What is new in 1.3.0

**Jaffer can now remove past conversations, and the companion can be bigger.**
- **Remove past conversations:** a trash button on each row, *Remove…* for a folder or everything listed, or `Delete` on a selected row. They go to the **Trash**, after a question, never deleted for good.
- **Safe by design:** a conversation that Claude Code is running in Jaffer is left alone, and nothing is moved without your click on *Move to Trash*.
- **Companion size:** *Settings → Appearance → Companion size* (small, normal, large, huge) for the mole and every scene.
- **Everything from 1.2.0** is included: it was never announced as the latest version.

**Jaffer can now move past conversations to the Trash, one at a time or a whole folder at once, and the mole (or any other companion) can be made bigger.** It is still one window, one shell and a companion with one side panel: no tabs, no splits, no second window, no chat box. Nothing is typed into your shell except `claude` and, after your own action, the resume line of a past conversation. 1.2.0 was never signed or announced as the latest version: 1.3.0 includes everything from it, so the notes of 1.2.0 below this one still apply.

### Removing past conversations
- **Where.** Each row in the side panel's *Past conversations* has a trash button (*Move to Trash*, shown on hover or focus, like the star). *Remove…* in the header opens a small menu: *This folder (N)* (only while a folder chip is active) and *All listed (N)*, where N is what the list shows (at most the 50 newest and your pinned ones, narrowed by the search). `Delete` or `Backspace` on a selected row removes that one (not while you type in the search box).
- **Always a question first.** A macOS dialog names the number (*Move 3 past conversations to the Trash?*). *Cancel* is the default button and Esc cancels. Nothing moves until you click *Move to Trash*. The number can be lower than the one in the menu: conversations that are running or already gone are left out.
- **What moves.** For each conversation, its transcript (`<id>.jsonl` in `~/.claude/projects/<folder>/`) and, when there is one, its sibling folder `<id>/` where Claude Code keeps the subagent transcripts and tool results. Nothing else. Jaffer finds those paths itself and only for real files and folders: a link is never followed or moved.
- **What never moves.** A conversation that Claude Code is running in Jaffer's terminal right now is refused (*still running*). If Jaffer cannot check that, it moves nothing and says so. Jaffer never deletes anything outright, never empties the Trash and never touches a file it did not list.
- **After it moves.** The conversations leave your pins and names, the list reads again and a message says how many went to the Trash and why any did not. This is the only time Jaffer changes Claude Code's files.

### How to get one back
Open the Trash in the Dock, select the conversation's file (a `.jsonl` named by its id, and its folder if it had one) and choose *File → Put Back*. Claude Code can then resume it again, and it shows in the list the next time it is read.

### Companion size
*Settings → Appearance → Companion size* has four choices: small (0.75 times), normal, large (1.5 times) and huge (2.25 times). It applies to the mole and to every scene, grows from the bottom right corner, never takes a click and never moves the terminal. A large size is kept to half the terminal's width and height, so on a small window *huge* shows smaller than 2.25 times.

### Limits, honestly
- The real move to the Trash and the macOS dialog have not been used on a real Mac yet: the README's *Not verified here* lists them. The code is tested with a stand-in Trash and a stand-in dialog.
- The *still running* check knows only the conversations that Jaffer's own hooks report. A `claude` running in another terminal app is not seen, so its conversation can be moved (it is in the Trash and can be put back).
- A very small window shows a large companion smaller than the setting says.

**What happens when you update**
- The update itself moves and deletes nothing. One new setting appears with its default: `appearance.petSize` (`normal`). Jaffer's hooks in `~/.claude/settings.json` stay as they were.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
