## What is new in 1.6.7

**Jump between failed commands.** ⌥⌘↑ and ⌥⌘↓ scroll to the closest command above or below that ended with an error, and flash it for a moment.
- **Select Output** (⌥⌘A, also in a command's right-click menu) selects the output of the last command, or of the command at the top of the view when you have scrolled up. ⌘C copies it.

<!-- card-end -->

**Jaffer 1.6.7 adds three keys for the command blocks.** A failed command is one with a known, non-zero exit code; a command whose exit code is not known is skipped. Clicking a block's mark in the gutter already selected its output, and *Select Output* is the same selection from the keyboard. Nothing is typed, sent or written, there is no new setting, and no signing, entitlement or update setting changes. The notes of 1.6.4 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
