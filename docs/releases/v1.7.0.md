## What is new in 1.7.0

**Resume a past conversation while Claude is running.** Click a past conversation while Claude waits at its prompt, and a question appears under the terminal's chip: *End the conversation running here and resume it?*
- **End and resume** types `/exit` into that terminal, waits until the shell is free, then resumes the one you picked. **Cancel** (the default) types nothing. While Claude is working, the command is copied, as before.

**Jump between failed commands.** ⌥⌘↑ and ⌥⌘↓ scroll to the closest command above or below that ended with an error. **Select Output** (⌥⌘A, also in a command's right-click menu) selects the output of the last command.

**Jaffer 1.7.0 rolls up 1.6.6 and 1.6.7, which were never released on their own.** The one fixed line Jaffer may type into a running Claude is `/exit`: only after your click on *End and resume*, only into that terminal, only while its Claude is idle and *Settings → Privacy and permissions → Resume typing* is on. If the shell is not free within 10 seconds, nothing more is typed and the resume command is copied. The failed-command keys scroll and select only; a command whose exit code is not known is skipped. No new setting, nothing is stored or sent. No signing, entitlement or update setting changes. The notes of 1.6.5 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
