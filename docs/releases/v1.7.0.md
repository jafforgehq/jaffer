## What is new in 1.7.0

**A more alive companion.** It thinks before Claude's first tool call, winces when a command fails, packs boxes while Claude compacts and waves when Claude has waited for you a minute. A dirt pile (a gauge on the scenes) grows with the context window. Every scene reacts too, and there are two new companions: a **Cat** and a **Garden**.
- **A companion per terminal, and a corner.** *Companion for this terminal: next* (palette) gives one terminal its own; *Companion corner* in Settings moves it left. It fades while text is under it.
- **Now card, calmer.** The last 5 hours, the turn bars and today's list sit behind *More details*.
- **Title bar and terminals.** A running command shows how long it has run, and a terminal in an ssh session gets an outline and a chip (red when the host looks like production; the host is never shown).
- **Copy tools.** *Copy last output* (⌥⌘K), *Copy fix prompt* on a failed command (copied for you to paste, never typed), *Copy turn card* as an image, and *Failed* and *Slowest* in ⌘R.
- **Theme by folder.** *Settings → Appearance → Theme by folder*: `~/code/prod-api=Ember`.

**Jaffer 1.7.0 adds two settings** (`appearance.petCorner` and `appearance.folderThemes`, both only what you choose or type). Nothing is typed into your terminal, nothing is sent, and everything copied is redacted. No signing, entitlement or update setting changes. The notes of 1.6.4 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
