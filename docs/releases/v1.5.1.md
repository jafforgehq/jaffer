## What is new in 1.5.1

**Voice mode is removed.** The voice controls (speaking Claude's replies, dictating into the prompt) and everything that came with them are gone.
- No voice setting, no `/voice` command, no *Shell → Voice Mode*, no model download.
- The app is back to the 1.5.0 behaviour, and the licence is back to what it was in 1.5.0.

<!-- card-end -->

**Jaffer 1.5.1 takes voice out again.** Voice was never released, so nothing you have installed changes except that it does not appear. It adds no setting, writes nothing new to disk and changes no signing, entitlement or update setting. The notes of 1.5.0 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
