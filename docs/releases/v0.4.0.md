## What is new in 0.4.0

**Companions.** The mole is no longer the only thing in the corner. Pick one in *Settings → Appearance*, where each choice is shown live:

- **Mole**, as before: digs while something runs, a helper for every agent.
- **Matrix**: digital rain; every background agent is a brighter, coloured column.
- **Agent network**: a hub and up to three nodes passing packets back and forth.
- **Warp**: a starfield at speed, a wingman ship per agent.
- **Radar**: a sweep and a blip per agent.
- **Reactor core**: counter-rotating rings, energy bars and orbiting agents.

All of them follow Claude Code and your commands the same way the mole does: asleep when nothing runs, working while something does (harder the longer it takes), an alert when Claude needs you, a celebration when a turn ends. They stand still with *Animations* off or macOS *Reduce motion* on, ignore the mouse and take their colours from your theme. The *Pet* switch is now *Companion*.

**Also new**
- **Resume Claude Code after a restart.** After a reboot, an update or a crash, a quiet *Resume Claude* button in the title bar types `claude --resume <id>` for the conversation that was running in that folder. Only when you click it, never after you quit Claude on purpose. Off in *Settings → Claude Code*.
- **Claude finished.** A notification when a turn that took half a minute or more ends while Jaffer is in the background, with how long it took and what it cost. Off in *Settings → Claude Code*.
- **Risky places are marked.** An amber edge under the title bar on a protected branch and a red one that names the host while `ssh` runs. Your own branch list and an off switch are in *Settings → Appearance*.
- **Keep the screen for a restart** is now a switch. Off keeps nothing of the screen on disk (the folder still comes back).

**Under the hood:** about 80 new tests, including a geometry suite for the scenes and UI tests for the picker, every scene's motion, bounds and reduced-motion behaviour. The README was rewritten.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
