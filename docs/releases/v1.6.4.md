## What is new in 1.6.4

**The last line of the terminal is no longer cut off.** At some window heights, full screen included, the bottom row was partly or wholly hidden.
- The terminal now counts its rows from the space that is really there.

<!-- card-end -->

**Jaffer 1.6.4 fixes a fit bug.** The terminal's padding sat on the wrapper, and the fit code subtracted only its own padding, so it counted up to 16 px too many and the last row ended below the visible area. The padding now sits where the fit code expects it. The look is the same, except that the scroll bar sits at the very edge of the terminal. It adds no setting, writes nothing, types nothing and changes no signing, entitlement or update setting. The notes of 1.6.3 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
