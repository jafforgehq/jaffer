## What is new in 1.6.5

**Other programs can no longer run code as Jaffer.** Jaffer's own binary could be started as a plain Node.js runtime, so another program on your Mac could run its code under Jaffer's signature and borrow the permissions macOS gave Jaffer. That is now switched off.
- The terminal host and the `jaffer` command run on Node.js 24, which now comes inside the app.
- The app takes about 116 MB more on disk.

<!-- card-end -->

**Jaffer 1.6.5 closes a local security gap.** Electron's RunAsNode, `NODE_OPTIONS` and `--inspect` fuses are off, and the `allow-dyld-environment-variables` entitlement is gone. The terminal host and the CLI run on the official Node.js 24.22.2 runtime (pinned and checked against its SHA-256 at build time, signed with the app) with `--disable-sigusr1`, and the host no longer passes `NODE_OPTIONS` on. The `~/.jaffer/bin/jaffer` wrapper is written again at the first start, at the same path, so Claude Code's hooks keep working. It adds no setting, writes nothing new, types nothing and changes no update setting. The notes of 1.6.4 and earlier still apply.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
