## What is new in 0.3.1

- **Everything lines up.** The folder pill in the title bar is now centred on the window itself (it sat a few pixels to the left, and further with a long folder name), and in a narrow window the Memory drawer lies over the terminal card instead of covering the title bar.
- A test now measures the layout at three window sizes, with and without the drawer, so it stays aligned.
- Memory written by older versions is checked on every release: old episodes, old journals and half-written lines all load, learn and undo as before.

Updating from 0.2.x or 0.3.0 asks first, as always. 0.1.x apps have no updater: install this version from this page once.
