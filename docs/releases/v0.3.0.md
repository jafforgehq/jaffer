## What is new in 0.3.0

- **A calm terminal.** Jaffer is now just the terminal: a thin title bar (folder, branch, what is running, a *Memory* button) and a little mole in the corner. The sidebar, the Claude panel, the status bar and the gutter stripes are gone. The mole sleeps when nothing runs, digs while a command or Claude works, sits up with a `!` when Claude needs you and cheers when a turn ends. The ring in the title bar spins only while something is really working.
- **Memory stays, quietly.** It still learns by itself, with one drawer to see, edit, pin and undo it (`⇧⌘M`). It now interrupts you only for something new it learned, never for housekeeping.
- **Claude is optional.** Install and sign-in help moved to *Settings → Claude Code*; the first run offers a plain terminal. Connect Claude Code and the mole and the notifications follow it.
- **Less code, fewer surprises.** About a thousand lines of unused code went (a command-injection API nothing used, leftovers of the old in-app agent, dead styles, unused screenshots and docs). One real fix came with it: the memory curator now knows what a `[CORRECTION]` in a transcript means.

Updating from 0.2.x asks first, as always. 0.1.x apps have no updater: install this version from this page once.
