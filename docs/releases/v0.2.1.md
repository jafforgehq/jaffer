## What is new in 0.2.1

- **No more "Working" for ever.** Pressing Esc in Claude Code (or declining a prompt) fires no hook, so the panel could stay on *Working* with its animation running indefinitely. Jaffer now reads Claude's own transcript for that moment, and a turn that goes silent (an API error, a crash) becomes idle by itself. Rows that never finished stop spinning.
- **Start Claude Code from the first run.** A new switch, *Start Claude Code in the terminal now* (on by default), types `claude` for you when you press *Get started*. Claude Code's own questions (trust this folder, allow a tool) stay in the terminal and are always yours to answer.
- **Simpler first run.** The *Connect Claude Code* switch is now *Show what Claude is doing in the panel* and installs only the hooks. The MCP server (memory tools for Claude) is a choice in *Settings → Claude Code*. *Get started* is always in view, also in a short window.

This is the first update 0.2.0 can offer you: Jaffer asks, and nothing installs without your yes.
