## What is new in 0.4.1

A hardening release after an independent review of 0.4.0. Nothing new to learn; a few things now do what they say.

**Fixed**
- **A config value of the wrong kind can no longer break Jaffer.** `jaffer config set safety.protectedBranches main,prod` used to store the text "main,prod", which blanked the window; a `null` section could stop the daemon starting; `session.restoreScreen off` quietly kept the screen on disk. Every value is now checked against the kind of its default when the config is loaded and when it is changed, and `jaffer config set` tells you when it refused one.
- **Resume Claude:** turning *Offer to resume Claude Code* off now really forgets the conversation. A hook that arrives just after you quit Claude can no longer bring that conversation back. `claude --version` or `claude mcp list` no longer drop an offer that is waiting after a restart.
- **"Claude finished"** is no longer sent for a turn you stopped with Esc or declined, or one that went quiet after an error.
- **The ssh tint** no longer names the host of a command the window hides as sensitive (a command typed with a leading space, a key file), redacts the host like any other text, and finds the host through `ssh -vp 2222 host`, `sudo -iu deploy ssh host`, `env X=1 ssh host` and `nice ssh host`.
- **Accessibility:** the protected-branch and ssh state is now text a screen reader reads (not a label on a plain element), and dismissing *Resume Claude* returns the focus to the terminal. The companion picker takes one step per arrow press even when a key repeats quickly. Every animation on the page has its own SVG ids.
- A message decoder that hit an error in one listener used to drop the rest of that network chunk; it now delivers the rest.

**Under the hood:** the update path and everything signed are unchanged from 0.4.0. 23 more unit tests and a stricter UI test for the picker, the status text and the focus.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
