## What is new in 0.2.0

- **One Claude.** The panel is no longer a second chat. You talk to the `claude` in the terminal, and the panel shows what it is doing live: working, idle or *needs you*, the tool it is running, a short activity list, subagents and its last reply. It listens through Claude Code's own hooks (async, silent, only inside Jaffer). You get a desktop notification when Claude needs you and Jaffer is in the background.
- **Sign in first.** A new first-run step checks that Claude Code is installed and you are signed in, before anything else. Jaffer runs on your Claude subscription only: the Anthropic API key option is gone.
- **Motion.** The panel and the sidebar look alive while Claude works (a breathing status pill, an equaliser, a sweeping line, rows that slide in, a pop when a tool finishes). Switch it off in *Settings → Appearance → Animations*; it also stands still under macOS *Reduce motion*.
- **Updates.** Jaffer checks GitHub for new signed releases, downloads one in the background and **asks** before installing: *Update and restart* or *Later*. Updating ends your terminal session, so the prompt says so (and says it again when Claude is working). Nothing installs without your yes. *Jaffer → Check for Updates…* and *Settings → Updates* give you control. Updates start with this version: 0.1.x apps do not have them, so install 0.2.0 from this page once.
- Removed: Gemini and Codex integrations, the panel's chat, `jaffer ask`.

If an earlier version stored an Anthropic API key, its Keychain item is no longer used. To remove it: `security delete-generic-password -s Jaffer -a anthropic-api-key`.
