## What is new in 0.3.2

- **A helper mole for every background agent.** When Claude Code starts background agents, a helper mole (up to three) digs on its own molehill beside the main one, and cheers and leaves when its agent finishes. Background agents outlive the turn that started them, and so do their moles.
- **The longer something works, the harder its mole works.** After half a minute a mole digs faster, after two minutes it sweats, after five it puts on a hard hat and its pile of dirt grows. A helper follows the age of its own agent, so the oldest one is the most worn out. With Animations off the hat and the pile still tell you how long it has been.
- **What each answer cost.** After every answer from Claude Code a small figure appears in the title bar (`≈ $0.04`); hover for the tokens behind it and the session total. It is an estimate from the token counts in Claude Code's own transcript at Anthropic's API list prices (only the numbers are read, never the words). On a Claude subscription you are not billed per token, so read it as what the work would be worth. A model Jaffer has no price for shows its tokens instead of a guess, and background agents' own usage is not included. Switch it off in *Settings → Claude Code → Show what each answer cost*.
- Background agents are settled when their session ends or goes quiet for half an hour, so a crashed Claude Code never leaves moles digging.

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
