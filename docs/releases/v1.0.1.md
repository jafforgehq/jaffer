## What is new in 1.0.1

**A menu bar icon, a close button that hides instead of stopping, and a list of your past Claude conversations.** Jaffer is still one window, one shell and a companion: no tabs, no splits, no second window, no chat box, and nothing is ever typed into your shell except `claude`.

### The close button no longer leaves you stuck
- **The red ✕ and `⌘W` hide the window, and the terminal runs on.** Before, closing a window that was in full screen could leave you in an empty Space with nothing to click. Now a window in full screen leaves full screen first and then hides. The first time, one notification says where Jaffer went ("Jaffer is still running in the menu bar").
- Nothing stops when the window hides: your shell, Claude Code and its hooks keep running. Click the menu bar icon, press your global hotkey or click a notification to bring the window back.
- You decide in *Settings → Appearance → Window → When I close the window*: **Hide to the menu bar** (the default), **Quit Jaffer** (it asks first when Claude Code or a command is running, as `⌘Q` does) or **Ask** (a question each time: *Hide to Menu Bar*, *Quit Jaffer* or *Cancel*; Cancel is the default).

### The menu bar item
- **It shows what Claude Code is doing:** the mole asleep when it is idle, digging while it works, and a dot when Claude needs you (the icon flashes three times, then stays on the dot). Optionally a short text beside it: this session's cost, the running turn's time or today's cost (*Settings → Appearance → Window → Menu bar text*; the costs follow *Show what each answer cost*, and are estimates, as everywhere).
- **Click** the icon to show the window, or to hide it when it is in front. **Right-click** for the menu: what Claude is doing (and, when it needs you, what it asks), *Show / Hide Jaffer*, *Recent Commands* (your last five; picking one **copies** it), *Past Conversations* (your last five; picking one **copies** `claude --resume <id>`), *Focus Mode*, *Settings…* and *Quit Jaffer*. Hold `⌥` when you open the menu for more lines: the cost so far, what this turn did (`3 reads, 2 edits`) and the git counts.
- **Only in the menu bar:** *Settings → Appearance → Window → Only in the menu bar* hides the Dock icon. It needs the menu bar icon (it is switched off while the icon is off), because the icon and your hotkey are the way back. *Show Jaffer in the menu bar* turns the icon off altogether (then closing still hides the window, the Dock icon and your hotkey bring it back, and *Ask* just hides).
- **Notifications have a *Show* button** for *Claude needs you* and *Claude finished*; the button and a click on the notification both bring the window back, also a hidden one.

### Past Claude conversations
- **`⇧⌘O`** (also in the palette, in the *Shell* menu and in the menu bar icon's menu) lists the last 50 conversations Claude Code kept, newest first: when it ended, the folder, how long it lasted and an estimated cost. Type to filter by folder.
- **Enter or a click copies `claude --resume <id>` to your clipboard** and says so. Nothing is typed into the terminal: pasting it and pressing Return is yours.
- **What is read.** Jaffer opens Claude Code's own transcripts (`~/.claude/projects/*/*.jsonl`, or `$CLAUDE_CONFIG_DIR/projects`) read-only and takes only the conversation's id (the file name), its folder, its first and last time and, for the newest 30, the token counts for the cost estimate. It never takes a prompt, a reply or a tool's input, never follows a link out of that folder, and the list is rebuilt when you ask and kept only in memory, never saved. The cost is an estimate at API list prices, as before, and follows *Show what each answer cost*.

**What the rules say now.** Two rules were narrowed on purpose. `⌘W` used to only hide the window; it now follows *When I close the window* (so it quits when you choose that). And Jaffer reads Claude Code's transcripts for more than token counts, but only the four things above. Everything else holds: no screen, scrollback, command history, command output or transcript text is written to disk, everything shown is redacted, and the menu bar's recent commands live in memory only. The only thing added to your settings file is a `window` section (`closeAction`, `menuBar`, `menuBarOnly`, `menuBarTitle` and a flag for the one hint notification).

**What happens when you update**
- Nothing is moved or deleted. The new settings appear in `~/.jaffer/config.json` with their defaults the first time they are saved, and the menu bar icon is on from the first start.
- Jaffer's hooks in `~/.claude/settings.json` are unchanged (the same eleven events). Updating from 0.5.x or earlier still runs the one-time clean-up of 0.6.0 (see below).

**By hand**
- Not yet checked on a real Mac, and not verified until the owner has checked it there: the menu bar icon and its three states in a light and a dark menu bar; the right-click menu, including what `⌥` adds; closing in full screen across Spaces; hiding the Dock icon, and whether `⌘Q`, `⌘W` and the hotkey keep working then; the notification *Show* button; the first-hide notification; the *Ask* dialog; the menu's *Past Conversations* waiting up to 400 ms on the first, cold call; `⇧⌘O` through the real menu; and the past-conversations list against the transcripts that real Claude Code versions write. The older checks of the 0.6 and 1.0.0 lines are still open too; the README's "Not verified here" lists them all.
- `claude --resume` and `claude -c` are yours to type or paste, as before.

**Coming from 0.5 or earlier?** Jaffer has been a plain terminal since 0.6.0: the memory, the saved screen, *Resume Claude* and *Restart Claude Code*, the login agent and the Safety edges are gone, and quitting ends the shell and anything running in it (`⌘Q` asks first when Claude Code is working or a command runs; a logout, restart or shutdown and the Dock's *Quit* do not ask). On the first start Jaffer cleans up what they left, once (up to 30 seconds): it removes the login agent, **copies `~/.jaffer/memory/NOTES.md` and `POLICY.md` to `~/.jaffer-memory-backup/`** if you wrote something in them, **deletes `~/.jaffer/memory` and `~/.jaffer/session`**, removes only Jaffer's own entries from Claude Code's files (the marked block in `~/.claude/CLAUDE.md`, the `jaffer-*` skills, the `jaffer` MCP server) and drops the settings that no longer exist. **To keep anything from the memory, copy `~/.jaffer/memory` before you open this version for the first time** (if you update from inside the app, copy it before you click *Update and restart*). `jaffer config set migrated 0` runs the clean-up again; *Settings → Reset* does the same and more. If an older Jaffer's session is still running in the background, one dialog asks to end it (the default button is Quit).

Updating from 0.2.x or later asks first, as always. 0.1.x apps have no updater: install this version from this page once.
