## What is new in 0.2.2

- **Claude is optional.** The first-run sign-in has a new way past it: *Use Jaffer as a plain terminal for now*. It installs nothing, starts nothing and sends nothing to Claude; the Claude panel (`⌘J`) connects Claude Code whenever you want it, and nothing nags in the meantime. Jaffer is a terminal first; Claude Code is what makes it special when you connect it.
- **Spinners that mean something.** The toolbar and sidebar no longer spin the whole time `claude` is open: they spin only while Claude is actually working, and a calm dot shows otherwise. They also stop with *Settings → Appearance → Animations*.
- **A little mole.** It lives in the sidebar, sleeps when nothing runs, digs while a command or Claude works, sits up when Claude needs you and cheers when a turn ends. *Settings → Appearance → Pet* turns it off.
- **Start over.** *Settings → Reset* and `jaffer reset` take Jaffer off your Mac for a clean install, keeping a backup of `~/.jaffer` unless you choose to delete it. Claude Code itself is never touched.
- **A README that matches the app**, with new screenshots.
