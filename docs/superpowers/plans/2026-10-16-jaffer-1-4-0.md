## Global Constraints
- THE PERSON'S REAL MAC: temp HOMEs only; never start the app against the default home; tests never run the real `claude`, `claude mcp list`, `claude -p`, `shell.trashItem`, `launchctl`, `caffeinate`; never read `~/.claude.json` (Claude's credential file). Never delete the repo's `release/` folder. Never push/tag/publish in a task.
- Calm window: new UI only where the spec says; existing allowed children of `.workspace/.stage/.terminal-area` unchanged (panes live inside `.panes`); no title-bar buttons; theme tokens only; check `styles.css` for class clashes (new prefixes: `.pn-` panes, `.pv-` privacy, `.sx-` setup, `.lr-` learn/tour, `.ex-` explain, `.st-` storage); reduced motion respected.
- Text from transcripts: only what the spec names (context/usage numbers, titles, explain's one reply when permitted, deep search ids). Redaction of anything shown from commands/payloads. Bounded helpers get 1 MB/8 MB timing tests.
- Existing test names stay unless deliberate (the three single-session guards change on purpose). Commit trailer EXACTLY `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (Sonnet tasks: `Claude Sonnet 5.5`). No CI/entitlement/signing/electron-builder change.
- Menu ids are one-line palette actions `{ id: '…'` in `src/renderer/actions.ts` with unique accelerators (`test/menu-spec.test.ts`).
- Verify: `npm run typecheck`; `node scripts/gen-shell.mjs --check`; `node scripts/gen-release-notes.mjs --check`; `npm run build`; `JAFFER_NO_LAUNCHCTL=1 npm test`; UI file `JAFFER_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npx vitest run --config vitest.e2e.config.ts test/e2e/ui.test.ts` (run twice back to back; wait for settled state in tests, never read once right after a selector).

## Review Focus
1. Multi-pane correctness: events keyed by pane everywhere; one pane's exit/close never ends another pane's Claude session; per-connection attach/detach and backpressure per pane; resume typing only into the focused, idle pane; quit asks for any pane.
2. Privacy/permissions: explain gated and tools disabled; deep search ids only; setup readers never open `~/.claude.json`; MCP check only on click, output redacted, args/URLs never shown.
3. Linux CI: no date/season/timing assumptions, no `\n`/`\r` line starts, no inherited computed styles.
