# 1.0.1: menu bar item, close button, past Claude conversations: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the spec as Jaffer 1.0.1, signed and published.

**Architecture:** History data in the daemon first, then the menu bar and close behaviour in main (pure decision modules + thin Electron wiring), then the renderer (history overlay, Settings), then docs and the release.

**Tech Stack:** TypeScript, Electron main (Tray, Menu, nativeImage, Notification), Node daemon, Preact renderer, vitest, Playwright-core UI tests.

**Spec:** `docs/superpowers/specs/2026-10-14-jaffer-1-0-1-design.md` (binding). **Context:** `.superpowers/sdd/2026-10-13-jaffer-1-0/` reports and feature map (lines drift: search by name).

## Global Constraints
- THE PERSON'S REAL MAC: no test or run touches the real `~/.claude`, `~/.jaffer`, `launchctl`, `caffeinate`; never start the app with the default home. The repo's `release/` folder holds the owner's running app. `JAFFER_NO_LAUNCHCTL=1` stays. Transcript reading is read-only and only what the spec's ruling lists; a symlink or path outside the projects directory is never opened; ids pass `isSessionId`.
- Nothing is typed into the shell (the only typed thing stays `claude`); clipboard only. No second window. Nothing new on disk except config keys and the generated tray icons in `src/generated`.
- New config section `window` with defaults exactly: `closeAction: 'menubar'`, `menuBar: true`, `menuBarOnly: false`, `menuBarTitle: 'off'`, `hintShown: false` (DEFAULT_CONFIG, type, conform tests). Anything displayed about commands goes through `safeCommand`/redaction; scans of untrusted text are bounded with 1 MB/8 MB timing tests.
- Tests of kept behaviour keep their names; name-diff every touched test file against the task BASE. Commit trailer EXACTLY `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push/tag/publish in a task. No CI/entitlement/signing change.
- Verify: `npm run typecheck`; `node scripts/gen-shell.mjs --check`; `npm run build`; `npm test`; the UI file `JAFFER_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npx vitest run --config vitest.e2e.config.ts test/e2e/ui.test.ts`.

## Review Focus
1. Privacy of the history list: only id, cwd, timestamps, token usage; no transcript text ever reaches the daemon's output; paths confined; bounded reads; async (does not block the daemon).
2. Close/quit semantics: ✕ and ⌘W hide, full screen is left first, no way to lose the window with the menu bar item off, Quit asks only through the in-app/tray Quit, system quits never ask.
3. Tray lifecycle: created once, destroyed on quit, no timers leaking (working animation, flash), no crash when icons fail to load, dock hide/show toggling.
4. Nothing typed, nothing opened from clipboard items; menu labels clipped and redacted.
