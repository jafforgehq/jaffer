# Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude's replies are read aloud with Kokoro and the person dictates into Claude's prompt with Whisper, both local, started from a `/voice` palette command, behind one off-by-default setting.

**Architecture:** A Web Worker in the renderer runs Kokoro (`kokoro-js`) and Whisper (`@huggingface/transformers`) in WASM. Main downloads and verifies the model files into `~/.jaffer/voice/` and hands bytes to the page over one IPC channel (the page is a `file://` page, so it cannot fetch them). Pure modules in `src/shared` decide what is spoken, what may be typed, and when a recording ends.

**Tech Stack:** TypeScript, Preact signals, esbuild (`scripts/build.mjs`), vitest, `@huggingface/transformers`, `kokoro-js`, `phonemizer` (espeak-ng WASM).

**Spec:** `docs/superpowers/specs/2026-10-23-voice-design.md`

## Global Constraints

- `permissions.voice` default `false`; `voice.speed` default `1`; nothing else added to `config.json`.
- Audio is never written or logged. Dictated text is typed only under the five conditions in the spec's "Typing rule" and never with Enter (no `\r` or `\n` can survive cleaning); text is cut to 500 characters.
- Spoken text: assistant prose only, redacted, clipped to about 1,500 characters.
- Pause detection ends a recording after about 1.5 s of silence. Esc cancels; Esc twice leaves voice mode.
- English only. Whisper `base.en`. Kokoro sample rate 24000 Hz.
- The permission handlers grant `clipboard-sanitized-write`, plus `media` for audio only while `permissions.voice` is on. Nothing else.
- Model download: fixed HTTPS host list, pinned SHA-256 per file, `~/.jaffer/voice/` mode 0700, one module (`src/main/voice-models.ts`) does all network work for voice.
- New IPC handlers each call `trusted(e)`. A new daemon method is added to `ALLOWED_PAGE_METHODS` and the renderer calls it by string literal (`test/page-methods.test.ts`).
- Existing CSP already has `'wasm-unsafe-eval'` (`src/renderer/index.html`); do not widen it further.
- Run `npm run typecheck && npm test` before each commit; `npm run build` first when `src/daemon` or `src/core` changed.

## Review Focus

1. Dictation text carrying escape sequences or bracketed-paste markers (`\x1b[201~`), newlines or control characters: cleaned, never able to submit. Pinned in Task 5.
2. Whisper noise output (`[BLANK_AUDIO]`, `(music)`, `[Music]`, empty, punctuation only): treated as no speech, nothing typed. Pinned in Task 5.
3. Focus moves to another pane, or Claude starts working, between recording start and typing: text is copied, not typed. Pinned in Task 5 and Task 8.
4. A reply that is only code or tool output: nothing is spoken and no error shows. Pinned in Task 5.
5. The switch is turned off during a download, recording or speech: download aborts and partial files are removed; the mic closes. Pinned in Tasks 2 and 5.
