## Global Constraints
- THE PERSON'S REAL MAC: temp HOMEs only; never start the app against the default home; never touch the real `~/.claude`/`~/.jaffer`. Never delete the repo's `release/` folder.
- Calm window: the only new child of `.side-panel` is the What's New card; no new children of `.workspace`/`.stage`/`.terminal-area`; no global CSS class that clashes with an existing selector (check `styles.css`); theme tokens only; reduced motion/`animations:false` respected.
- Typing: only through the existing `resumeAction` path on a person's click/Enter/⇧⌘R. Nothing else typed. Redaction of anything shown from commands/payloads (`safeCommand`, `redactText` on clipped input). Bounded helpers get 1 MB/8 MB timing tests.
- New on-disk data: only the config keys in the spec. New in-memory data is named in CLAUDE.md (Task 7). Config keys need defaults of the right kind.
- Existing tests keep names except deliberate ones (say which and how). Name-diff every touched test file. Commit trailer EXACTLY `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (Sonnet tasks: `Claude Sonnet 5.5`). Never push/tag/publish in a task. No CI/entitlement/signing/electron-builder change.
- Menu ids must be palette actions on one line starting `{ id: '…'` in `src/renderer/actions.ts` (menu-spec test reads the source); accelerators unique (free: ⇧⌘R, ⌘/).
- Verify: `npm run typecheck`; `node scripts/gen-shell.mjs --check`; `npm run build`; `JAFFER_NO_LAUNCHCTL=1 npm test`; UI file `JAFFER_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npx vitest run --config vitest.e2e.config.ts test/e2e/ui.test.ts` (run twice).

## Review Focus
1. Privacy: names/pins/cwd/notes add no transcript text; folders and details shown only through redaction; approvals never answer without a click.
2. Typing safety unchanged: no new path types text; resume-last and palette reuse the lock and refusals.
3. Linux CI: no `\n`/`\r` line-start assumptions, no inherited computed styles, no date-dependent assertions without a fixed date.
