# Jaffer 1.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Ten small terminal improvements: a Terminals section in the side panel (add, close, rename, reorder, split here, zoom, close idle, per-terminal cost/context), a pet inside every terminal, state outlines, and notifications that name and focus the terminal.

**Architecture:** Pure helpers in `src/shared/pane-tools.ts`; window state (`paneLabels`, `zoomPane`, reorder) in `src/renderer/state.ts`; `PaneTree.tsx` renders the pets, the zoom and the outlines; a new `Terminals.tsx` panel section; main tracks each terminal's folder from daemon events and sends the page `app.focus-pane`.

**Tech Stack:** TypeScript, Preact signals, Electron main, vitest (unit, real PTY) and Playwright-in-vitest (`test/e2e/ui.test.ts`).

**Spec:** `docs/superpowers/specs/2026-10-21-jaffer-1-5-0-design.md` (read it; CLAUDE.md is binding and long: read the rules named in each task).

## Global Constraints
- CLAUDE.md rules hold: no new IPC channel, no new daemon method, no new config key, nothing written to disk, no typing into a shell, `ALLOWED_PAGE_METHODS` unchanged (only `pane.split`, `pane.close`, `session.restart`, `pane.list` are called, as today), every shown command goes through `safeCommand`, colours from theme tokens (`--line`, `--accent-line`, `--surface`, …), no global CSS class that is also a utility (`.row`), check a new class is not already a selector.
- Max four terminals, no tabs, no divider to drag in the grid, no title-bar buttons for terminals, no fifth terminal, no saved layout.
- The panel's children after this release, in order: handle, WhatsNew, Explain, Now, **Terminals**, Conversations, Setup.
- Every new `main.ts` dialog goes through the counting wrapper (none is expected). Any new `redactText(` call needs an entry in `test/invariants.test.ts` with its bound note.
- Menu accelerators stay unique (`menu-spec.ts` + its test); every menu id has a palette action id (`actions.ts`).
- Verify each task: `npm run typecheck` and the named tests; `npm run build` before daemon/core tests. UI tests: `JAFFER_CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npx vitest run --config vitest.e2e.config.ts test/e2e/ui.test.ts` (the whole file, one run; `-t` filters break it). Under load the UI file can have timing flakes: use `until(...)` waits, never fixed sleeps, and rerun a failing test once before concluding.
- Commit messages end with: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus
- A terminal closed while renamed/zoomed/dragged: no stale label on a reused id (`p2` reused), no zoom on a gone pane.
- Reorder with one terminal, with an unknown id, dropped on itself: list unchanged.
- Pets: reduce-motion and `appearance.pet=false` still hide/stop all of them; four pets must not slow input (CSS-only motion, timers only while active).
- Zoom: hidden terminals keep their pty size (no `pty.resize` while hidden), un-zoom does not leave a stale size.
- Notification text with a hostile folder name (control/format characters, 4096 chars): bounded, redacted, never throws.
- Label input: paste of 10 000 chars, RTL/format characters, only spaces.

### Task 1: Pure helpers and window state

**Files:**
- Create: `src/shared/pane-tools.ts`, `test/pane-tools.test.ts`
- Modify: `src/renderer/state.ts`

**Interfaces:**
- Produces (`pane-tools.ts`):
  - `cleanPaneLabel(raw: string): string`: removes `\p{Cc}\p{Cf}\p{Zl}\p{Zp}`, collapses whitespace to single spaces, trims, clips to 24 characters (by code point); `''` means no label. Input is clipped to 200 characters first (bounded).
  - `reorderPanes(list: string[], id: string, to: string): string[]`: moves `id` to the index `to` holds; returns a copy of `list` unchanged when either is not in it or they are equal.
  - `movePane(list: string[], id: string, dir: -1 | 1): string[]`: one step; unchanged at the ends or for an unknown id.
  - `idleToClose(list: string[], focused: string, busy: (id: string) => boolean): string[]`: every id that is not `focused` and not `busy(id)`; never returns all of `list` (the focused one always stays; if `focused` is not in `list` the first id stays).
- Produces (`state.ts`): `paneLabels: Signal<Record<string,string>>`, `setPaneLabel(id, raw)`, `paneName(id): string` (label, else folder base name of `paneInfo[id].cwd`, else `Terminal n`), `zoomPane: Signal<string|null>`, `toggleZoom(): void` (no-op with a toast "Only one terminal." at one pane; sets `zoomPane` to the focused pane or clears it), `reorderPane(id, to)` and `shiftPane(id, dir)` (write `panes.value` through the helpers). `removePane` also deletes that pane's label and clears `zoomPane` if it was the zoomed one; `addPane` clears `zoomPane`; setting `activePane` while `zoomPane` is set moves the zoom (do it where `activePane` is assigned for focus: wrap in a `focusPane(id)` helper used by `focusTerminal`, `cycleTerminal`, `splitTerminal`, the pane's `onMouseDown`, or add an effect on `activePane`).
