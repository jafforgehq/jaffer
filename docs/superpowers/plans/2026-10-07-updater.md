# Updates Implementation Plan

> **For agentic workers:** executed inline with superpowers:executing-plans (ledger: `.superpowers/sdd/2026-10-07-updater/progress.md`).

**Goal:** Jaffer finds a new signed GitHub release, downloads it in the background and asks before restarting into it.

**Architecture:** a pure policy module and an Electron-free `UpdateController` (injected updater, dialog, session shutdown) tested with fakes; `main.ts` wires the real `electron-updater`; the release script publishes `latest-mac.yml` last.

**Tech Stack:** electron-updater 6 (GitHub provider), electron-builder 26, Preact signals.

**Spec:** `docs/superpowers/specs/2026-10-07-updater-design.md`

## Global Constraints

- Ask first; nothing installs without a click, not even on quit.
- Only a Developer ID signed, packaged app checks; never a prerelease.
- No new window; native dialog only. Text from the feed is clipped before it is shown.
- Theme tokens only, no global modifier classes; CSS prefix `upd-` if any.
- Commit trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

- Update ready while Claude is working or waiting: the prompt says so.
- "Later" then the timer fires again with the same version already downloaded: no second prompt this launch.
- A check that hangs or fails (offline, GitHub 5xx): no dialog, no crash, next tick tries again.
- Quit with "Later" pending: nothing is installed behind the running session.
- The manifest names a version that is not newer, or a garbage version string: no prompt.

**Interfaces — Produces:**

- `promptText(o: { version: string; claudeBusy: boolean }): { message: string; detail: string; buttons: [string, string] }`
- `shouldAsk(o: { manual: boolean; declined: string | null; version: string }): boolean`
- `signerKind(codesignOutput: string): 'developer-id' | 'adhoc' | 'unsigned'`

- [ ] Tests first (RED): `cleanVersion('0.2.0')`, `'v0.2.0'` → null, `'0.2.0<script>'` → null, `42` → null; `promptText` message contains the version and the buttons are `['Update and restart', 'Later']`; detail always says the session ends and memory is kept; with `claudeBusy` it also says Claude is working right now; `shouldAsk`: manual → true; auto and `declined === version` → false; auto and another declined version → true; `signerKind`: output with `Authority=Developer ID Application: X (TEAM)` → developer-id, `Signature=adhoc` → adhoc, `code object is not signed at all` or empty → unsigned.

### Task 2: Controller

**Files:** Create `src/main/updates.ts`, `test/update-controller.test.ts`.

**Interfaces — Consumes:** Task 1. **Produces:**
```ts
export type UpdateStatus = 'unavailable' | 'idle' | 'checking' | 'downloading' | 'ready' | 'uptodate' | 'error';
export interface UpdateState { status: UpdateStatus; current: string; version?: string; error?: string; auto: boolean }
export interface UpdaterLike { on(ev: 'checking-for-update'|'update-available'|'update-not-available'|'update-downloaded'|'error', cb: (arg?: any) => void): unknown; checkForUpdates(): Promise<unknown>; quitAndInstall(silent?: boolean, forceRun?: boolean): void }
export interface UpdateDeps { updater: UpdaterLike; current: string; enabled: boolean; auto: () => boolean; ask(t: ReturnType<typeof promptText>, version: string): Promise<boolean>; claudeBusy(): boolean; prepareInstall(): Promise<void>; log(msg: string): void; onState?(s: UpdateState): void; firstCheckMs?: number; intervalMs?: number }
export class UpdateController { constructor(d: UpdateDeps); start(): void; stop(): void; checkNow(): Promise<UpdateState>; state(): UpdateState }
```
- [ ] Tests first (RED) with a fake updater (EventEmitter + `checkForUpdates` that fires events) and fake timers: disabled → `start` never checks and `checkNow` returns `unavailable`; auto off → timers do not check, `checkNow` does; `update-downloaded` → `ask` called once with the busy flag; accept → `prepareInstall` resolves before `quitAndInstall(false, true)` is called; Later → a second `update-downloaded` for the same version (auto) does not ask, but `checkNow` does; a newer version after Later asks; `ask` rejecting → no install, state `ready`; updater `error` → state `error` with a clipped message, no throw; `checkForUpdates` rejecting → same; two overlapping `checkNow` calls call the updater once; garbage version in the event → ignored.
- [ ] Implement (timers via `setTimeout`/`setInterval`, `unref`'d); run the file → pass.
- [ ] Commit.
