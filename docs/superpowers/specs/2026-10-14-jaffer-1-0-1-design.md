# 1.0.1: a menu bar item, a close button that makes sense, and past Claude conversations

Date: 2026-10-14 · Status: scope decided by the owner in conversation ("I want those 10, it will go to version 1.0.1, and I also want sessions' history": answered "Past Claude conversations"). Facts about the code: the 1.0.0 feature map and reports in `.superpowers/sdd/2026-10-13-jaffer-1-0/`.

## Why
Since 0.6.0 the red ✕ only hides the window (the session lives as long as the app does). In full screen that leaves an empty Space with nothing to click: no way back. A menu bar item makes hiding useful, and a list of past conversations brings the one thing a plain terminal lost with the memory: finding an earlier Claude conversation.

## Rulings (rules this release narrows or keeps)
- **One window stays.** The ⌥-click "peek panel" idea would be a second window. It becomes the same menu with extra status lines (no panel).
- **Nothing typed.** A past conversation is picked by copying `claude --resume <id>` to the clipboard (after `isSessionId`); Jaffer never types it. Recent commands in the menu copy too.
- **Reading Claude's transcripts is widened, read-only:** besides token counts (existing cost code) Jaffer may read, in `~/.claude/projects/*/*.jsonl` (or `$CLAUDE_CONFIG_DIR/projects`), the **file name (the session id), the folder (`cwd` field of the first lines), the first and last timestamps** and the token usage of up to the 30 newest. It never reads, keeps or shows prompts, replies, tool inputs or anything else. It never writes there. Nothing from it is stored on disk by Jaffer (the list is rebuilt on request; a small in-memory cache keyed by path+mtime). Ids must match `isSessionId`; a path outside the projects directory is never opened (no symlink following out of it).
- Nothing else new on disk except config keys. Menu bar state (recent commands, status lines) is memory only.
- Calm: the menu bar item is the only new surface; no new windows.

## Features
1. **Close goes to the menu bar.** The red ✕ (also in full screen) leaves full screen first, then hides the window; the menu bar icon stays. The first time, one native notification: "Jaffer is still running in the menu bar" (`window.hintShown`). `⌘W` (Hide Window) does the same. Setting **When I close the window** (`window.closeAction`): `menubar` (default) | `quit` (the normal Quit flow, asking first when Claude or a command runs) | `ask` (a dialog: Hide to menu bar / Quit / Cancel; Cancel is the default button). **Ruling:** with the menu bar item off (`window.menuBar` false) ✕ still hides as today, but in full screen it first leaves full screen; the Dock icon brings it back.
2. **State icon.** A template (monochrome) image in the menu bar, tinted by macOS: idle, working (the digging mole, 2 frames alternating every 500 ms while working), alert (an alert dot). Icons are generated by `scripts/gen-tray-icons.mjs` into `src/generated/tray-icons.ts` (base64 PNGs at 1x and 2x), so nothing new is packaged; a unit test compares the generator output with the committed file. `window.menuBar` (default true).
3. **Click and menu.** Left click shows or hides the window (hidden window: show and focus). Right click opens the menu (Show Jaffer, status lines, recent commands, past conversations, Focus mode, Settings…, Quit Jaffer).
4. **Title text.** `window.menuBarTitle`: `off` (default) | `cost` (this session's estimate, `≈ $1.20`) | `time` (the running turn, `4m`) | `today` (today's estimate). Cost only with `claude.showCost`.
5. **Status lines in the menu.** First lines: "Idle", "Working · Bash · 1m 12s" or "Needs you: Bash" (tool name and notice, already redacted and clipped to 60); a click on the line shows the window. With ⌥ held when opening, extra lines: live cost, tool counts of this turn, git counts.
6. **Recent commands.** A submenu with the last 5 commands finished (memory only, kept in main from `pty.command`; sensitive commands and `safeCommand`-hidden ones left out; labels clipped to 60); a click copies the raw text to the clipboard.
7. **Menu bar only.** `window.menuBarOnly` (default false, needs `menuBar`): hides the Dock icon (`app.dock.hide()`); the icon and the hotkey bring the window back; shown again when turned off. Quit from the menu.
8. **(was: peek panel)** — see rulings: ⌥ extra lines.
9. **Notification route.** The needs-you and finished notifications get a **Show** button (macOS notification action) besides the click; both show the window even when it was hidden to the menu bar. The icon flashes the alert icon three times (400 ms) on a new needs-you.
10. **Quit from the menu.** Quit Jaffer in the icon menu follows the same rule as `⌘Q` (asks when Claude or a command runs; sets `askOnQuit`).
11. **Past Claude conversations.** ⇧⌘O / palette "Past Claude conversations…" / Shell menu item opens a list overlay (kind `history`) of the 50 newest conversations: relative date, folder (`~/…`), duration (first→last timestamp), cost (`≈ $0.42`, only with `claude.showCost`, only for the 30 newest and transcripts up to 24 MB, else "–"), a filter input over the folder; Enter or a click copies `claude --resume <id>` and toasts "Copied. Paste it in the terminal." The menu bar menu has a "Past conversations" submenu with the 5 newest (same copy). RPC `claude.history` → `{ items: { id, cwd, startedAt, endedAt, durMs, usd? }[] }`.

## Settings
Appearance gets a **Window** group (or a new "Window" page): *When I close the window* (select), *Show Jaffer in the menu bar* (switch), *Only in the menu bar (hide the Dock icon)* (switch, off when the menu bar is off), *Menu bar text* (select). Keys: `window: { closeAction: 'menubar', menuBar: true, menuBarOnly: false, menuBarTitle: 'off', hintShown: false }` (new section, defaults of the right kind). Key: ⇧⌘O.
